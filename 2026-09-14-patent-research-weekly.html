层并行推理架构 (Layer Parallelism for Inference)NEW

US20260268651A1 NVIDIA, 2026-09
核心创新: 提出一种层并行推理方法,将 Transformer 模型的多个层映射到不同 GPU 组同时执行,通过流水线通信重叠技术隐藏层间数据传输延迟,显著提升大模型推理吞吐量。

技术实现:

  • 将 LLM 的不同 Transformer 层分配到多组 GPU 上并行处理,打破传统顺序推理瓶颈
  • 利用 NVLink/NVSwitch 高速互连实现层间激活值的低延迟传输
  • 结合流水线调度策略,将通信延迟与计算重叠,减少 GPU 空闲等待
  • 支持动态层分配,根据模型结构和硬件拓扑优化并行度

影响分析: 层并行推理为超大模型 (万亿参数级) 提供了新的推理扩展维度,与张量并行和流水线并行形成互补。结合 NVIDIA Blackwell Ultra 和 Rubin 平台的 NVLink 5 拓扑,可实现更高效的分布式推理。

来源: Google Patents - US20260268651A1

动态神经网络硬件分配系统 (Dynamic Neural Network Hardware Assignment)NEW

US20260169817A1 NVIDIA, 2026-09
核心创新: 根据神经网络模型的实时计算需求和硬件状态,动态分配 GPU、内存和互连带宽资源。系统通过运行时监控和预测模型负载,自动调整硬件资源分配以最大化整体吞吐量。

技术实现:

  • 运行时分析神经网络各层的计算密度和通信需求
  • 根据实时负载动态调整 GPU SM 分配、内存带宽和 NVLink 通道
  • 支持异构硬件环境 (GPU + DPU + NIC) 的统一资源调度
  • 通过预测模型提前分配资源,避免推理/训练过程中的资源争抢

影响分析: 该专利体现了 NVIDIA 向"软件定义硬件"方向发展的趋势。在混合部署 (训练+推理) 场景下,动态硬件分配可以显著提高集群利用率,降低 TCO。

来源: Google Patents - US20260169817A1

多芯粒架构 MMU 同步机制 (Multi-Dielet MMU Synchronization)NEW

US11822491B2 系列 NVIDIA, 持续授权中
核心创新: 在多芯粒 (multi-dielet) GPU 架构中实现 MMU 页表的一致性同步。通过分布式 TLB 管理和跨芯粒页表更新协议,确保多个芯粒之间的虚拟地址映射一致性,同时最小化同步开销。

技术实现:

  • 每个芯粒维护独立的 TLB 缓存,通过一致性总线广播页表更新
  • 采用"主-从"页表架构: 主芯粒维护根页表,从芯粒缓存副本
  • 支持统一虚拟地址空间 (UVA),跨芯粒指针可直接解引用
  • TLB 失效时通过芯粒间高速互连快速获取远程页表项

影响分析: 随着 GPU 向多芯粒封装演进 (如 Blackwell 的双芯粒设计),MMU 同步成为关键挑战。该方案为超大地址空间 GPU 提供了可扩展的内存管理基础。

缓存感知 GPU 内存处理 (Cache-Aware GPU Memory Processing)NEW

US20260205432A1 NVIDIA, 2026
核心创新: 根据 GPU L1/L2 缓存状态动态调整内存访问模式。通过分析数据访问的时空局部性,自动选择最优的数据布局和数据预取策略,减少缓存未命中,提升内存带宽利用率。

技术实现:

  • 硬件性能监控单元实时追踪 L1/L2 缓存命中率
  • 基于访问模式分析,动态切换数据在 HBM 中的存储布局 (行优先/列优先/分块)
  • 自适应预取引擎根据历史访问模式预测未来数据需求
  • 支持 CUDA 级别的缓存提示 (cache hint) 指令,让程序员参与优化

影响分析: 在 LLM 推理场景中,KV Cache 的内存访问模式高度不规则。缓存感知技术可显著提升 KV Cache 读取效率,减少推理延迟。结合 Blackwell 的 192GB HBM3e,可进一步提升有效带宽。

来源: Google Patents - US20260205432A1

NCCL 2.27: 对称内存与 NIC 直连 (Symmetric Memory & Direct NIC Connect)NEW

NVIDIA NCCL 2.27 NVIDIA Developer Blog, 2025
核心创新: NCCL 2.27 引入三大核心特性: (1) 对称内存 (Symmetric Memory) 实现跨 GPU 的统一内存视图,消除数据搬运; (2) NIC 直连 (Direct NIC Connect) 让 GPU 直接与远程 NIC 通信,跳过中间 CPU 拷贝; (3) SHARP 卸载将集合通信归约操作 offload 到交换机芯片。

技术实现:

  • 对称内存: 所有 GPU 通过 NVLink/NVSwitch 共享统一虚拟地址空间,支持远程 GPU 内存的直接 RDMA 访问
  • NIC 直连: GPU 通过 PCIe/CXL 直接连接 NIC,数据路径从 GPU→CPU→NIC 简化为 GPU→NIC
  • SHARP 卸载: AllReduce 的归约操作在 InfiniBand 交换机上执行,减少 GPU 计算开销
  • 与 NCCL SoL 论文 (arXiv 2607.16100) 形成互补: 论文提供理论分析,NCCL 2.27 提供工程实现

影响分析: NCCL 2.27 标志着 GPU 集合通信从"软件优化"进入"软硬件协同"阶段。对称内存模型与 CUDA Unified Memory 深度集成,开发者无需修改代码即可享受跨 GPU 内存共享的性能提升。

来源: NVIDIA Developer Blog - NCCL 2.27

分层堆叠内存网络 (Hierarchical Stacked Memory Network)NEW

US20260244578A1 NVIDIA, 2026
核心创新: 设计分层内存拓扑结构,将 HBM、L2 Cache 和共享内存组织为多层堆叠网络。每层具有不同的带宽/延迟特性,通过智能路由策略将数据请求导向最优存储层,最大化有效内存带宽。

技术实现:

  • Layer 0: HBM3e (4.8 TB/bank) → Layer 1: L2 Cache (50+ MB) → Layer 2: 共享内存/寄存器文件
  • 智能数据放置策略: 热数据自动提升到更快层,冷数据下沉到 HBM
  • 跨 GPU 的 L2 Cache 一致性协议,支持远程 L2 命中
  • 与 NVLink 域结合,实现跨节点的内存池化 (memory pooling)

影响分析: 该架构为 NVIDIA Rubin 平台的"内存墙"突破提供了基础。在 LLM 推理中,KV Cache 可分布在多层存储中,热 token 保持在 L2,冷 token 下沉到 HBM,有效解决 KV Cache 内存爆炸问题。

来源: Google Patents - US20260244578A1

Fabric 连接内存与 ICMS KV Cache 存储 (Fabric-Attached Memory & ICMS)NEW

NVIDIA GTC 2025 / Rubin Platform NVIDIA, 2025-2026
核心创新: Rubin 平台引入 Fabric-Attached Memory 架构,将 HBM 从 GPU 封装中解耦,通过 NVLink Fabric 连接独立内存模块。同时 ICMS (Intelligent Cache Memory System) 提供专用 KV Cache 存储,将推理内存容量从单 GPU 的 192GB 扩展到 TB 级。

技术实现:

  • Fabric-Attached Memory: HBM 模块通过 UCIe 接口连接 NVLink Fabric,任意 GPU 可访问
  • ICMS: 专用 KV Cache 存储系统,支持动态分配/回收,避免 GPU 显存碎片化
  • 内存解耦合使 GPU 计算与内存容量独立扩展
  • 200G SerDes + 光电共封装 (CPO) 提供 Fabric 互连带宽

影响分析: Fabric-Attached Memory 是 NVIDIA 向"组合式架构 (Composable Architecture)"迈出的关键一步。它打破了 GPU 内存容量与计算能力的绑定关系,为超大规模 LLM 推理提供了更灵活的内存扩展路径。

来源: NVIDIA Rubin Platform | Tom's Hardware - Rubin

NVLink 6 对称内存架构 (NVLink 6 Symmetric Memory Architecture)NEW

NVIDIA NVLink 6 / Rubin NVIDIA, 2026
核心创新: NVLink 6 在 Rubin 平台实现 10 TB/s 双向互连带宽 (较 NVLink 5 提升 2.5x),并原生支持对称内存语义。每个 NVLink 域可连接 576 GPU,支持跨 GPU 的原子操作和远程内存访问,延迟接近本地内存。

技术实现:

  • 10 TB/s 双向带宽: 基于新一代 SerDes 和信号编码技术
  • 对称内存语义: 硬件级支持跨 GPU 的 load/store 操作,无需软件层面数据拷贝
  • 576 GPU NVLink 域: 通过 NVLink Switch (NVSwitch 4) 实现全互连拓扑
  • 硬件原子操作: 支持跨 GPU 的原子加、比较交换等操作,加速分布式训练中的梯度归约

影响分析: NVLink 6 的对称内存语义使得多 GPU 编程模型趋近于单 GPU 编程模型。开发者可以使用统一指针访问任意 GPU 内存,硬件自动处理数据迁移和一致性。

来源: NVIDIA Rubin Platform

AMD 计算通信并行专利

非均匀芯粒 GPU 架构 (Non-Homogeneous Chiplets)NEW

US12367174B2 AMD, 2025-07
核心创新: 将 GPU 分为多个芯粒,每个芯粒具有相同的核心计算单元但不同的缓存/加速器配置。有源桥接器 (Active Bridge) 在所有芯粒间创建统一的 L3 缓存,对操作系统呈现为单一设备。调度器将 AI 工作负载导向具有 ML 加速器的芯粒,渲染任务导向具有特定着色引擎的芯粒。

技术实现:

  • 有源桥接器芯粒包含统一 L3 缓存,维护所有芯粒间的数据一致性
  • 主-从路由: 主机处理器与一个主 GPU 芯粒通信,主芯粒分配流量到从芯粒
  • OS 看到单一聚合设备,简化编程模型
  • 灵活的芯粒配置: 不同芯粒可针对 AI 推理或图形渲染优化

影响分析: 该架构是 AMD MI300/MI400 系列多芯粒 GPU 的基础。通过芯粒级别的异构配置,AMD 可以在单一 GPU 中同时优化 AI 计算和图形渲染,提高芯片面积利用率。

来源: Google Patents - US12367174B2

平衡延迟堆叠缓存 (Balanced Latency Stacked Cache)NEW

US20260003794A1 AMD, 2026-01
核心创新: 垂直堆叠的缓存层通过基底芯粒上的集中控制逻辑实现平衡延迟访问。中央垂直互连在双内存阵列部分之间实现对称延迟 (从 14 周期降低到 12 周期),消除 3D 堆叠导致的延迟不均匀性。

技术实现:

  • 控制逻辑和标签字段位于基底芯粒,与堆叠的内存阵列分离
  • 中央定位的硅通孔 (TSV) 或键合焊盘过孔创建平衡延迟
  • 更短的内部布线降低电容、功耗和热量
  • 与 3D V-Cache 技术协同,优化 GPU 缓存访问延迟

影响分析: 3D 堆叠缓存的延迟不均匀性是制约其性能的关键因素。AMD 的平衡延迟设计确保所有缓存区域具有相同的访问延迟,对计算通信重叠中的缓存流水线至关重要。

来源: Google Patents - US20260003794A1

稀疏 GPU 内存分配 (Sparse GPU Memory Allocation)NEW

US20260179302A1 AMD, 2026-06
核心创新: GPU 采用两阶段稀疏分配: 首先预留虚拟地址空间而不立即分配物理 RAM,然后通过提交指令按需绑定/解绑物理内存到子范围。仅填充当前可见的 Tile,最小化 VRAM 浪费并减少卡顿。

技术实现:

  • 阶段一: 分配请求预留虚拟地址范围
  • 阶段二: 提交指示器按需绑定或解绑物理内存到特定子范围
  • 仅当前可见/激活的 Tile 占用物理内存
  • 与 ROCm 运行时集成,提供透明的稀疏内存管理 API

影响分析: 稀疏内存分配对 MoE 模型 (如 DeepSeek-V3) 特别有价值——仅激活的专家占用物理内存,非激活专家可延迟加载。在有限 VRAM 的 GPU 上可支持更大规模的模型。

来源: Google Patents - US20260179302A1

有源桥接芯粒与集成缓存 (Active Bridge Chiplet with Integrated Cache)NEW

US11507527B2 AMD, 2022 (基础专利)
核心创新: 有源硅桥接芯粒作为高速互连和内存交叉开关,连接多个 GPU 芯粒。统一的共享 L3 缓存维护所有连接模块间的数据一致性。软件将多个离散芯粒视为一个统一设备。

技术实现:

  • 主-从路由设置: directing traffic between dies
  • 物理结构避免 GPU 芯粒内部的 TSV,依赖桥接器进行所有跨芯粒通信
  • 是 AMD MI300 系列多芯粒 GPU 的基础架构专利

影响分析: 该专利是 AMD 多芯粒 GPU 架构的基石。有源桥接器使计算和内存可以分布在多个芯粒上,同时维护一致的内存模型,这是计算通信重叠的关键前提。

来源: Google Patents - US20210097013A1

网络缓存注入 (Network Cache Injection for Coherent GPUs)NEW

US11687460B2 AMD, 2023 (授权)
核心创新: 将网络接收的数据直接注入 GPU 本地缓存层级,绕过主内存以减少缓存未命中延迟。使用一致性追踪和预取机制,将网络数据预加载到 GPU 缓存中,加速分布式训练中的通信-计算重叠。

技术实现:

  • 网络接口接收数据后,通过一致性追踪器通知 GPU
  • GPU 评估过滤条件决定是否将数据预加载到本地缓存
  • 两种方式: (1) NIC 直接注入 GPU 缓存; (2) NIC 写入主内存并发送失效消息作为提示
  • 减少 AllReduce 等通信操作后数据到达 GPU 计算单元的延迟

影响分析: 网络缓存注入直接解决了分布式训练中"通信完成后数据仍需从主内存搬运到 GPU"的瓶颈。在计算通信重叠场景中,可将通信后数据就绪时间缩短 30-50%。

来源: Google Patents - US20180314638A1

UALink 1.0 开放互连标准 (UALink 1.0 Open Interconnect Standard)NEW

UALink Consortium AMD/Intel/Google/Meta 主导, 2025
核心创新: UALink 1.0 规范定义了加速器 (GPU/TPU/NPU) 之间的开放互连协议,支持最多 1024 个加速器的全互连拓扑。基于内存语义 (load/store) 和消息语义 (message passing) 的混合通信模型,提供与 NVLink 竞争但完全开放的替代方案。

技术实现:

  • 内存语义: 支持跨加速器的 load/store 操作,实现统一内存访问
  • 消息语义: 支持消息传递模式,适用于集合通信
  • 物理层: 基于 100G SerDes,可通过 CPO (光电共封装) 扩展距离
  • 1024 加速器域: 通过 UALink Switch 实现全互连,超越 NVLink 的 576 GPU 限制

影响分析: UALink 1.0 是 AMD、Intel、Google、Meta 等公司联合对抗 NVIDIA NVLink 封闭生态的关键举措。开放互连标准将降低加速器市场的进入壁垒,促进异构计算生态的发展。

来源: UALink Consortium Specification

  • 快速任务可降低资源以维持同步,实现全局最优

影响分析: 直接针对分布式 AI 训练中 AllReduce 的"落后者"问题。通过 IPU 的自适应管理,可最大化 AllReduce 操作的效率,这是数据并行训练的主要瓶颈。

LLM 数据预取优化 (Data Pre-Fetch for LLM Processing)NEW

US20240370699A1 Intel, 2024-11
核心创新: 在 LLM 推理中重叠计算与数据搬运: 当前层计算时,预取器将下一层的权重矩阵和 KV-Cache 传输到本地暂存区 (Scratchpad Memory、LLC 或内存侧缓存)。在低利用率时段执行数据传输,减少向量-矩阵乘法延迟。

技术实现:

  • 暂存区可以是 Scratchpad Memory、LLC 或内存侧缓存

  • 硬件级别的计算-通信并行实现

影响分析: 这是软件层面"计算通信重叠"技术在硬件层面的直接实现。Intel 的方案将 LLM 推理中的数据搬运延迟隐藏在计算时间内,可显著降低每 token 的推理延迟。

来源: Google Patents - US20240370699A1

芯粒间侧带接口 (Sideband Interface for Die-to-Die Interconnects)NEW

US12321305B2 Intel, 2025-06

技术实现:

趋势展望

内存解耦合成为核心架构趋势

NVIDIA 的 Fabric-Attached Memory 和 Intel 的 XBM BEOL DRAM 从不同角度指向同一方向: 内存与计算的解耦合。NVIDIA 通过 NVLink Fabric 将 HBM 从 GPU 封装中解耦,Intel 通过 BEOL 工艺消除硅中介层。这意味着未来 AI 芯片的内存容量可以独立于计算能力扩展,打破"HBM 容量 = GPU 显存"的绑定关系。

三大开放互连竞争格局进一步巩固: NVIDIA NVLink Fusion (有限开放, 576 GPU)、UALink 1.0 (完全开放, 1024 加速器)、华为 UB 2.0 (开源, 8192 节点)。UALink 和 UB 2.0 的规模都超过 NVLink 限制,展示了开放标准的后发优势。AMD、Intel、Google、Meta 联合推动的 UALink 正在成为 NVLink 之外最有力的替代方案。

参考: UALink | 华为 UB 2.0

MoE 通信优化成为系统研究热点

本周有 4 篇论文/专利直接针对 MoE 通信优化: DisagMoE (解聚合集群)、Tile-level MoE Overlap (Tile 级重叠)、MoE Resource Management (资源管理)、AMD 稀疏内存分配。MoE 模型 (DeepSeek-V3, Qwen 3 235B) 的普及带来的 All-to-All 通信挑战,使其成为 2026 年系统研究的最大热点之一。

参考: DisagMoE | Tile-level MoE | MoE Resource

SM 竞争驱动通信架构创新

TokenWeave (2-8 SM)、VCCL (零 SM)、Resource-aware (自适应) 三种方案独立揭示了同一核心矛盾: 通信内核与计算内核争夺 GPU SM 资源。随着 GPU SM 数量持续增长 (Blackwell: 192 SM),通信内核的 SM 占比虽小,但对计算性能的干扰不容忽视。三条解决路线: 最小化 SM 占用、完全卸载到拷贝引擎/CPU、资源感知动态分配。

参考: TokenWeave | VCCL | Resource-aware

芯粒架构成为竞争基础

本周三家公司都在芯粒架构上有重要专利: NVIDIA 的多芯粒 MMU 同步、AMD 的非均匀芯粒 + 有源桥接器、Intel 的 UCIe 侧带接口。芯粒架构不仅是制造良率的解决方案,更成为了计算通信并行的物理基础。有源桥接器提供的统一 L3 缓存、UCIe 的可靠互连、MMU 的一致性同步,都是实现高效计算通信重叠的前提。

参考: AMD Non-Homogeneous | Intel UCIe | NVIDIA MMU

壁仞科技"光跃128卡商用版"落地标志着光互连技术正式进入商用阶段。NVIDIA Rubin 集成 200G SerDes + CPO,华为 Atlas 实现 200m+ 光互连,OptPipe 论文优化光互连流水线。三大趋势汇聚: GPU 内部 NVLink C2C 光互连、机柜内光电共封装、跨机柜全光交换。光互连将重新定义 AI 数据中心的物理拓扑。
